YOLŊU CULTURAL EDGE THEME

This bundle contains:
1. Yolngu_Cultural_Theme — the actual browser theme.
2. Yolngu_Daily_Words — optional companion extension for automatic 30-day New Tab rotation.

INSTALL:
1. Extract the ZIP.
2. Open Microsoft Edge and enter edge://extensions
3. Turn on Developer mode.
4. Click Load unpacked.
5. Select Yolngu_Cultural_Theme.
6. Optional: repeat Load unpacked and select Yolngu_Daily_Words.

If either package was already loaded before this update, open edge://extensions and select
Reload for it (or remove it, then use Load unpacked again). Select the two folders above,
not the parent bundle folder.

The theme changes Edge browser chrome and uses Day 1 as its static New Tab artwork.
The companion extension supplies the automatic 30-day wallpaper/word cycle because a browser
theme itself is a static package and cannot run JavaScript to rotate images.
